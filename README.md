# Retrospective COVID-19 Analytics in Europe Using the OWID Dataset

## Overview

This project explores the COVID-19 pandemic across European countries using publicly available data from [Our World in Data (OWID)](https://ourworldindata.org/coronavirus).

The analysis takes a retrospective approach to examining pandemic-related data, using data analytics and visualisation techniques to explore trends and compare the impact of COVID-19 across Europe.

The project was completed as part of the **Visualisation for Data Analytics (CSC-40048)** module at Keele University during the 2024–2025 academic year.

## Project Objectives

- Explore COVID-19 data across European countries.
- Examine changes in reported COVID-19 cases and deaths over time.
- Use data visualisation to communicate trends and comparisons.
- Apply data analytics techniques to investigate patterns in the dataset.
- Present the analysis through visual outputs and supporting code.

## Dataset

The project uses the Our World in Data COVID-19 dataset, which provides country-level and time-series information relating to the pandemic.

**Original data source:**  
[Our World in Data – COVID-19 Dataset](https://github.com/owid/covid-19-data)

The dataset is included in the repository under the `Dataset` directory.

## Methodology

The project follows a data analytics workflow:

1. **Data collection:** Obtain COVID-19 data from the Our World in Data dataset.
2. **Data preparation:** Load and prepare the data for analysis.
3. **Exploratory analysis:** Examine the available variables and identify patterns across countries and time periods.
4. **Visualisation:** Generate charts and visual outputs to communicate the analysis.
5. **Evaluation:** Review the analytical outputs and supporting results.
